## What It Does

2K Shot Meter is a small web-based utility for repeating jump shot timing exercises in NBA 2K games. Its button-oriented interface lets players practice release timing directly in a browser without installing a separate desktop application.

First determine the timing measurement for the jump shot you want to work on, then enter that number in milliseconds. The configured interval becomes the reference for the practice session, allowing repeated drills and adjustments when moving between different shots.
